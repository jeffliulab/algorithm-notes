#### 1011. Capacity To Ship Packages

这道题是875 koko吃香蕉的变体。注意，设置left最小边界的时候，一定要注意，不能设置为1，否则会导致错误。为什么呢？假如要运送的包裹是2，那么你的船载重是1的话，根本就无法运送，但是计算却会继续进行，导致最终拿到一个错误的答案。所以最低的left左边界要设置成最重的包裹重量，确保每一个包裹都起码能被运走！
