## Breakout Game

This project can be divided into two parts. The first part is Reinforcement Learning, the second part is Deep Learning.

I handle all the details for the first part, but the second part I plan to optimize in this fall semester, I have a course of optimization in deep learning to take. Also, I have contacted Prof.Sinavp to continue doing Reinforcement Learning Project.


How to solve:

1. Make the breakout into 10x10 grid, make it solvable with Q-learning
2. Use OpenCV to detect the ball
3. The performance is very low, because the ball is not a significant object
4. Then I build a perfect environment, which only has 10 times 10 grid, and the ball's position information can be read.
5. Then I build the Q-learning Model, and solve it perfectly.
6. Back to breakout, I build the Q-learning model, and upgrade it into DQN. So start from this point, I use AI tools to generate deep learning related codes.
